Resolve one exact mint

Every valid mint returns a typed envelope. Unreviewed mints stay singletons; pending proposals remain separate from reviewed relationships. Resolver envelopes cap reviewed incident edges at 100 and disclose eligible/included counts plus truncation. ENTITY AGGREGATION CONTRACT

Denominators stay visible.

One contribution

Each entity trend has at most one exact-mint contributor. Grouped entities require a reviewed primary or sole reviewed variant; unreviewed singletons remain separate and contribute only their own mint. Variant volume is never summed into a louder entity. Every row labels whether it uses a radar evidence score, five-minute volume, momentum, or launch-observation recency fallback.

Missing stays missing

Included and excluded variants plus narrative, lifecycle, and volume coverage retain explicit mint counts and separate registry/token timestamps.

Proposals stay out

Unreviewed identity proposals cannot group mints, change the mint leaderboard, or affect entity trend selection.

Live weak consistency

Cursor order is stable by entity ID, but a changing live tape can add or remove singleton rows between page requests.

PUBLIC GET + STREAM SURFACE

One contract, bounded roles.

GET /api/health, /api/snapshot, exact-mint dossiers and timelines, comparisons, frozen briefs, identity endpoints, and the OpenAPI document return sanitized read-only evidence. Snapshot-dependent reads share one immutable computed result for at most five seconds; generatedAt identifies that evidence time, and cross-process database commits invalidate the cache immediately. GET /api/stream is a non-replayable sanitized SSE surface with a process-local cap of 64 concurrent connections. POST /api/agent/chat runs only the local deterministic analyst over the supplied snapshot; it has no external model, wallet, or execution capability.

FILESYSTEM BOUNDARY

HTTP writes nothing.

Filesystem-writing vault exports are outside this public contract. Legacy daily, weekly, and coin-export HTTP routes fail closed with typed HTTP 403 in every mode before snapshot or vault access. A trusted operator can instead run npm run vault:export from a local shell.

RATE + ERROR CONTRACT

Bounded public use

Snapshot, entity-list, and resolver attempts each share separate process-global 120/minute buckets per instance; local analyst attempts share 60/minute. Successful responses include X-RateLimit-Limit, X-RateLimit-Remaining, and X-RateLimit-Reset. HTTP 429 adds Retry-After. Readiness is not rate-limited. Buckets and aggregate-only counters reset with the process and do not coordinate across replicas.

No identity or market guarantee. Entity and primary labels describe reviewed identity resolution only—not authenticity, safety, common control, quality, performance, or a trade recommendation.
